# vctx-template

This is a template repository for creating `vctx` projects. It is configured with a GitHub Codespace `devcontainer` that automatically:
- Uses the `vctx-lang` compiler Docker image
- Installs the `vctx-language-support` VS Code extension
- Exposes `vctx` as a global terminal command

## Getting Started

1. Click **Use this template** -> **Create a new repository**.
2. Once your repository is created, click **Code** -> **Codespaces** -> **Create codespace on main**.
3. Open a `.vctx` file and start coding!
